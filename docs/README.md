## Orden de lectura antes de la Semana 01

1. [setup-entorno.md](setup-entorno.md) — sin el laboratorio arriba, la primera práctica no arranca
2. [divergencia-distros.md](divergencia-distros.md) — para saber qué esperar cuando el bootcamp diga "en RHEL es distinto"
3. [proyecto-hilo-conductor.md](proyecto-hilo-conductor.md) — qué es `toolkit` y por qué lo arrastras veinte semanas
4. [autograding.md](autograding.md) — para saber cómo se te evalúa

Vuelve a [trucos-linux.md](trucos-linux.md) al terminar cada semana: crece
contigo.
