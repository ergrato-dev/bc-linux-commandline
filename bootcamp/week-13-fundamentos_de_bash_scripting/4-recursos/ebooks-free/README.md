# Ebooks gratuitos — Semana 13

| Recurso | Por qué vale la pena | Comprobado |
|---|---|:--:|
| [The Linux Command Line (William Shotts)](https://linuxcommand.org/tlcl.php) | Mismo libro de semanas anteriores: su cuarta parte, *Writing Shell Scripts*, recorre un script desde el shebang hasta el control de flujo con el mismo enfoque práctico de esta semana | 2026-10-25 |
| [Bash Guide for Beginners (Machtelt Garrels, TLDP)](https://tldp.org/LDP/Bash-Beginners-Guide/html/) | Guía gratuita para quien empieza a escribir scripts: variables, condicionales y argumentos con ejemplos cortos, justo el orden de los archivos 01 a 06 | 2026-10-25 |
| [BashGuide (Greg's Wiki)](https://mywiki.wooledge.org/BashGuide) | Explica con precisión por qué hay que entrecomillar, cómo se expande una línea y qué hace cada tipo de prueba: la base del archivo 03 | 2026-10-25 |
| [Advanced Bash-Scripting Guide (Mendel Cooper, TLDP)](https://tldp.org/LDP/abs/html/) | Referencia enorme y gratuita; úsala **para consultar**, no para leer de corrido: tiene ejemplos útiles y otros anticuados | 2026-10-25 |
| [Bash Reference Manual (GNU)](https://www.gnu.org/software/bash/manual/bash.html) | El manual oficial de bash, la fuente de verdad de las expansiones y los condicionales de los archivos 02, 03 y 05 | 2026-10-25 |
