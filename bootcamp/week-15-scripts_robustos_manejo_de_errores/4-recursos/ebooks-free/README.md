# Ebooks gratuitos — Semana 15

| Recurso | Por qué vale la pena | Comprobado |
|---|---|:--:|
| [The Linux Command Line (William Shotts)](https://linuxcommand.org/tlcl.php) | Mismo libro de semanas anteriores: su cuarta parte (*Writing Shell Scripts*) cierra con el manejo de errores y las señales que aquí se estudian a fondo | 2026-10-24 |
| [Writing Shell Scripts, lección 15: errores, señales y `trap` (linuxcommand.org)](https://linuxcommand.org/lc3_wss0150.php) | La versión web del curso de Shotts: `trap`, códigos de salida y limpieza con otros ejemplos, para contrastar con los archivos 02 y 03 | 2026-10-24 |
| [Bash Reference Manual (GNU)](https://www.gnu.org/software/bash/manual/bash.html) | El manual oficial: los apartados *The Set Builtin*, *Bourne Shell Builtins* (`trap`, `getopts`) y *Exit Status* son la fuente de verdad de los archivos 01 a 03 y 07 | 2026-10-24 |
| [Advanced Bash-Scripting Guide: códigos de salida (TLDP)](https://tldp.org/LDP/abs/html/exitcodes.html) | Tabla de códigos reservados (`126`, `127`, `128 + N`) en una página; úsala **para consultar**, porque el resto de la guía mezcla ejemplos útiles con otros anticuados | 2026-10-24 |
