solo proyecto — `toolkit` — que crece capa a capa.

La columna **Estado** dice la verdad sobre el repositorio: ✅ la semana está
publicada al estándar de `CLAUDE.md`, ⬜ todavía no se escribió. El contenido
se escribe en orden, una semana por entrega.
