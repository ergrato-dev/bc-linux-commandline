# Ebooks gratuitos — Semana 19

| Recurso | Por qué vale la pena | Comprobado |
|---|---|:--:|
| [The Linux Command Line (William Shotts)](https://linuxcommand.org/tlcl.php) | Mismo libro de semanas anteriores: sus capítulos sobre permisos y procesos refuerzan los archivos 05 y 07 | 2026-10-25 |
| [systemd for Administrators (Lennart Poettering)](https://0pointer.net/blog/projects/systemd-for-admins-1.html) | Serie de artículos del autor de systemd; explica unidades, `systemctl` y el arranque con el criterio de quien lo diseñó. Es de 2010: los comandos básicos siguen valiendo, contrasta lo demás con el manual | 2026-10-25 |
| [OWASP Docker Security Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Docker_Security_Cheat_Sheet.html) | Lista de reglas para endurecer contenedores; cada punto corresponde a una bandera del archivo 08 | 2026-10-25 |
| [NIST SP 800-190: Application Container Security Guide](https://csrc.nist.gov/pubs/sp/800/190/final) | Guía oficial y gratuita sobre riesgos de contenedores; sitúa lo que `harden container` no ve (imágenes, orquestador, anfitrión) | 2026-10-25 |
