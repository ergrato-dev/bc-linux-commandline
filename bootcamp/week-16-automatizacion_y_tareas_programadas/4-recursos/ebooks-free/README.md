# Ebooks gratuitos — Semana 16

| Recurso | Por qué vale la pena | Comprobado |
|---|---|:--:|
| [The Linux Command Line (William Shotts)](https://linuxcommand.org/tlcl.php) | Mismo libro de semanas anteriores: su parte de scripting sirve de base para las tareas que aquí se programan | 2026-10-25 |
| [Bash Reference Manual (GNU)](https://www.gnu.org/software/bash/manual/bash.html) | La fuente de verdad de la sustitución de parámetros (`${var//a/b}`), los arrays asociativos y `10#` que usa `schedule` | 2026-10-25 |
| [Linux System Administrator's Guide (TLDP)](https://tldp.org/LDP/sag/html/) | Guía clásica y gratuita de administración: sitúa `cron` en el conjunto del sistema; úsala como contexto, que algunas partes son antiguas | 2026-10-25 |
