# Ebooks gratuitos — Semana 14

| Recurso | Por qué vale la pena | Comprobado |
|---|---|:--:|
| [The Linux Command Line (William Shotts)](https://linuxcommand.org/tlcl.php) | Mismo libro de semanas anteriores: su cuarta parte (*Writing Shell Scripts*) trata los bucles, las funciones y los arrays con el mismo enfoque práctico de esta semana | 2026-10-25 |
| [Writing Shell Scripts (linuxcommand.org)](https://linuxcommand.org/lc3_writing_shell_scripts.php) | La versión web del curso de Shotts, lección a lección; las lecciones 11 y 13 (*Flow Control*) son los archivos 01 y 02 de esta semana con otros ejemplos | 2026-10-25 |
| [BashGuide: arrays (Greg's Wiki)](https://mywiki.wooledge.org/BashGuide/Arrays) | Explica con precisión los arrays indexados y asociativos, `"${a[@]}"` y los huecos: la base de los archivos 04 y 05 | 2026-10-25 |
| [Bash Beginners Guide: bucles (TLDP)](https://tldp.org/LDP/Bash-Beginners-Guide/html/chap_09.html) | Guía gratuita con ejemplos cortos de `for`, `while`, `until`, `break` y `continue`, para repasar el archivo 01 | 2026-10-25 |
| [Advanced Bash-Scripting Guide: funciones (TLDP)](https://tldp.org/LDP/abs/html/functions.html) | Referencia enorme y gratuita; la sección de funciones recoge `return`, `local` y la recursión. Úsala **para consultar**: mezcla ejemplos útiles con otros anticuados | 2026-10-25 |
| [Bash Reference Manual (GNU)](https://www.gnu.org/software/bash/manual/bash.html) | El manual oficial: los apartados *Shell Functions*, *Arrays* y *Looping Constructs* son la fuente de verdad de los archivos 01 a 05 | 2026-10-25 |
